## 🛠 Technology Stack

This repository focuses on **Identity-First** and **Data-Driven** operations using the modern Microsoft ecosystem.

### **☁️ Cloud & Infrastructure**
* **Microsoft Endpoint Manager (Intune):** Device Compliance, Remediation Scripts, Autopilot.
* **Azure:** Automation Accounts, Logic Apps, Azure Functions (Serverless), Log Analytics.
* **Identity:** Microsoft Entra ID (formerly Azure AD), Managed Identities, Service Principals.

### **💻 Development & Data**
* **Python:** `pandas`, `streamlit`, `requests`, `msal`, `beautifulsoup4`, `diagrams`.
* **PowerShell:** Graph SDK, Azure Modules, Advanced Function Scripting.
* **APIs:** Microsoft Graph API (Delta Sync patterns), Azure Monitor Logs Ingestion API.

---

## 📈 Architecture

1.  **Zero Trust:** No hardcoded secrets. Usage of Managed Identities and OAuth2 flows (MSAL).
2.  **Scalability:** Implementation of **Delta Queries** and **Parallel Processing** (Threading) for large tenants.
3.  **Observability:** Integrated logging to **Azure Monitor** and structured error handling.
4.  **Documentation-as-Code:** Architectures are defined and rendered programmatically using Python.
