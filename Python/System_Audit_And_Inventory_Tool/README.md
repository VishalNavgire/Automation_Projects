> **Cross-Platform | Audit-Ready | Enterprise Logging**  
A Python-based **system inventory and audit framework** designed to collect OS-independent and OS-specific system metadata with **enterprise-grade logging**, suitable for **Windows Server, Linux, Azure VMs, Intune-managed endpoints, and hybrid environments**.

---

## 📌 Project Purpose

In enterprise environments, administrators require **reliable, consistent, and auditable system inventory** across heterogeneous operating systems.
---

## ✅ What This Solution Collects

### 🔹 OS-Independent (All Platforms)

| Category | Description |
|--------|-------------|
| Hostname | Machine hostname |
| FQDN / Domain | Fully Qualified Domain Name |
| Disk Space | Free space on system/root drive |
| User Profiles | Local user home directories |
| Timezone-Aware Logs | Localized audit timestamps |

---

### 🔹 OS-Specific (Conditional)

| Platform | Data Collected |
|--------|----------------|
| Windows | Installed Updates (HotFixes), Installed Applications |
| Linux | Installed packages and user environments |
